Создать свой диалог

Импорт диалогов из JSON

Вставь JSON-массив в формате: [{"title":"...","situation":"...","role":"...","lines":[{"who":"me","es":"...","ru":"...","tr":"..."}]}]. Дубликаты по названию и битые записи не добавятся.

Диалог через ИИ-чат

Нажми кнопку — в буфер скопируется готовый промт. Вставь его в любой ИИ-чат, а сразу после него — тему (например, «в аптеке») или свой текст диалога. Полученный JSON верни в поле импорта выше.

Импорт и бэкап

Импорт слов из JSON

Вставь JSON в формате приложения: массив записей с полями es, ru, tr, ex. Дубликаты и битые записи не добавятся.

Импорт через ИИ-чат

Нажми кнопку — в буфер скопируется готовый промт. Вставь его в любой ИИ-чат вместе со своим сырым списком слов, получи в ответ JSON и вернись в поле выше.

Бэкап

Файл сохранится в загрузки. В бэкап входят и слова, и диалоги, и весь прогресс.

Восстановление: выбери файл бэкапа и нажми кнопку.
