Диалоги

Создать свой диалог

Импорт диалогов из JSON

Вставь JSON-массив в формате: [{"title":"...","situation":"...","role":"...","lines":[{"who":"me","es":"...","ru":"...","tr":"..."}]}]. Дубликаты по названию и битые записи не добавятся.

Диалог через ИИ-чат

Нажми кнопку — в буфер скопируется готовый промт. Вставь его в любой ИИ-чат, а сразу после него — тему (например, «в аптеке») или свой текст диалога. Полученный JSON верни в поле импорта выше.

Бэкап диалогов

Файл сохранится в загрузки. Свои диалоги хранятся отдельно от основной базы — у них свой бэкап.

Восстановление: выбери файл диалогов и нажми кнопку.

Импорт и бэкап

Импорт записей из JSON

Вставь JSON-массив в формате приложения: у каждой записи поля es, ru, tr, ex, exRu, type, priority; для глаголов — forms; для правил — ruleText и ruleQuestions. Дубликаты по полю es и битые записи не добавятся.

Импорт через ИИ-чат

Нажми кнопку — в буфер скопируется готовый промт. Вставь его в любой ИИ-чат вместе со своим сырым списком, получи в ответ JSON и вернись в поле выше.

Бэкап

Файл сохранится в загрузки. Храни его в надёжном месте.

Восстановление: выбери файл бэкапа и нажми кнопку.

Настройки

Связь с ботом

chat_id бот пришлёт в ответ на команду /start. При открытии из Telegram он подставится автоматически.

Размер тренировки

Сколько карточек в одной сессии (без учёта повторов).

Новых записей за тренировку

Сколько новых слов максимум попадает в одну сессию.

Сброс

Все записи станут новыми, стрик, история и статистика обнулятся. Сам словарь и настройки бота сохранятся. Отменить нельзя — сначала сделай экспорт, если бэкап нужен.

Важно про данные

Прогресс хранится в этом браузере (localStorage). Очистка данных сайта удалит его — делай бэкап раз в неделю.
